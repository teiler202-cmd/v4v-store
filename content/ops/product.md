> ✂️ 스타일 하나는 스타일 표의 한 행입니다. 단계를 다음으로 옮기기 전에
> 아래 통과 조건을 만족했는지 확인합니다.

## 파이프라인과 통과 조건

| 단계 | 다음 단계로 넘어가는 조건 |
|---|---|
| 기획 | 라인, 품목, 목표 판매가, 출시 예정일이 정해졌다 |
| 디자인 | 도식화와 사양서가 있고 원단과 부자재가 특정됐다 |
| 샘플 | 검수 표에 샘플 검수 기록이 있고 판정이 합격이다 |
| 생산 | 수량, 단가, 납기가 확정되고 선금이 지출에 기록됐다 |
| 입고 | 입고 검수 판정이 합격이고 원가가 확정됐다 |
| 판매중 | 촬영물, 상세 페이지, 재고가 스토어에 올라갔다 |
| 종료 | 재고가 소진됐거나 판매 중단을 결정했다 |

## 사양서에 반드시 들어가는 것

- [ ] 도식화 — 앞뒤, 주요 치수 표기
- [ ] 사이즈 스펙 — 기준 사이즈와 그레이딩 편차
- [ ] 원단 — 혼용률, 중량, 컬러, 공급처
- [ ] 부자재 — 라벨, 지퍼, 단추, 스티치 색상
- [ ] 프린팅 또는 자수 — 위치, 크기, 방식
- [ ] 케어 라벨과 사이즈 라벨 문구
- [ ] 패키징 사양

사양서가 없는 상태로 견적을 요청하지 않습니다.
말로 전한 조건은 나중에 근거가 되지 않습니다.

## 판매가는 원가에서 나온다

감으로 정하지 않습니다. 계산 규칙과 마진 기준은 [Finance](finance)에 있고,
스타일의 마진율이 자동으로 계산됩니다. 견적을 받으면 먼저 원가에 넣어
기준을 통과하는지 봅니다.

## 아카이브 규칙

스타일이 끝나도 행을 지우지 않습니다. 단계만 종료로 바꿉니다.
지난 원가와 불량률이 다음 시즌 견적의 유일한 근거입니다.
